ตัวจับเวลานำเสนอ (Presentation Timer)
00:00

💬 บทพูดนำเสนอตามขั้นตอน (Step-by-step Speech Script)

ขั้นตอนที่ 1: การกล่าวทักทายและแนะนำตัว ~ 30 วินาที

"สวัสดีครับ/ค่ะ อาจารย์และเพื่อนๆ ทุกคน ผมชื่อ [ธีรนันท์] นักศึกษามหาวิทยาลัยนอร์ทกรุงเทพ วันนี้ขออนุญาตนำเสนอ Web Design Showcase Portfolio ซึ่งเป็นเว็บไซต์คลังรวบรวมชิ้นงานและโปรเจกต์ภาคปฏิบัติทั้งหมดที่ได้จัดทำตลอดภาคเรียนครับ"

ขั้นตอนที่ 2: ภาพรวมสไตล์เว็บไซต์ Hub ~ 45 วินาที

"ตัวเว็บไซต์หลักนี้ถูกออกแบบในสไตล์ Neo-Brutalism เน้นความทันสมัย ลายเส้นขอบหนา และสีสัน High-contrast เพื่อความโดดเด่น มีฟังก์ชันกรองหมวดหมู่ผลงาน ทั้ง Web Applications, Google Sites และ Mini Games พร้อมระบบ Interactive Live Preview เพื่อให้อาจารย์ทดลองใช้งานได้ทันทีครับ"

ขั้นตอนที่ 3: ไฮไลต์ชิ้นงานสำคัญ (7 Projects) ~ 2-3 นาที
  • 🔹 Google Sites Home & Portfolio: เว็บไซต์แนะนำตัวและแฟ้มสะสมผลงานวิชาการบนระบบ Google Sites
  • 🔹 BMI Calculator Web App: แอปคำนวณดัชนีมวลกาย ประมวลผลสุขภาพด้วย JavaScript
  • 🔹 Open House Portal: เว็บไซต์ประชาสัมพันธ์กิจกรรมเปิดบ้านมหาวิทยาลัย
  • 🔹 Mini Game Project & Web -13: มินิเกมโต้ตอบและเว็บแอปพลิเคชันทดลอง นำขึ้นระบบออนไลน์ด้วย GitHub Pages
ขั้นตอนที่ 4: สรุปและเปิดโอกาสซักถาม ~ 30 วินาที

"จากการทำโปรเจกต์ทั้งหมดนี้ ทำให้ผมได้พัฒนาทักษะด้าน Web Development, UI/UX Design และการปรับแต่ง GitHub Pages ให้ใช้งานได้จริงครับ ขอขอบพระคุณอาจารย์อย่างยิ่ง และยินดีรับฟังคำแนะนำเพื่อนำไปพัฒนาต่อครับ ขอบคุณครับ"
